# 玻璃斗地主 0.2.0

Windows 透明桌面三人斗地主，房间号＋密码联机，包含十一种捣乱技能。客户端背景完全透明，半透明玻璃牌只绘制点数与花色；对手牌背无牌面信息。浏览器备用入口可以联机，但浏览器窗口不能透出真实桌面。

## 直接玩

[下载 Windows 免安装版](https://github.com/yss907732349/glass-landlord/releases/latest) · [创建 Render 免费房间服务](https://render.com/deploy?repo=https://github.com/yss907732349/glass-landlord)

Windows 免安装文件位于 `release/GlassLandlord-0.2.0-Windows.exe`。打开后创建房间并设置4～32位密码；也可添加两位陪练，准备后开始。新版已默认连接 https://glass-landlord.onrender.com ，朋友们无需手填地址；想离线玩，可在设置中点“使用本机服务”，再添加陪练。0.2.0改变了技能使用时机，三名玩家和房间服务都应更新到新版。

同一局域网：一人打开桌面版，在设置中查到或填写该电脑的服务地址，其他人连接它的局域网地址与端口。桌面版默认内置服务使用4318端口，若被占用则自动换一个空闲端口，可通过窗口服务地址查看。若使用固定服务，启动 `pnpm start` 默认监听 `0.0.0.0:4317`，朋友连接 `http://这台电脑的局域网IP:4317`；首次连接可能需要允许 Windows 专用网络防火墙。

公网：参考123项目，使用 **GitHub Pages（备用网页）＋Render 免费房间服务**。默认房间服务为 https://glass-landlord.onrender.com ，也可在设置中切换其他服务。GitHub Pages 自身不能运行联机服务。配置已放在 `render.yaml` 和 `.github/workflows/`，具体见 `docs/deployment.md`。

## 操作

- 点击手牌选择，或按住左键拖过多张牌批量选择／取消；选好后点“出牌”，也可在手牌区右键快速出牌。“提示”选择一组合法牌。赖子可在操作栏声明点数。
- 自己的出牌回合可以先用技能，再继续正常出牌；可以连续使用持有的技能。技能操作不弹窗：点技能、按需选择手牌、点对手头像选目标，再点“使用”。无需目标的技能直接点使用；悬停查看效果，点取消返回出牌。
- 顶部拖动把手移动整个界面；拖动左上角或右下角把手缩放，双击角落或点顶部百分比恢复位置与大小。设置可调整牌面透明度、缩放比例和布局锁定。
- 桌面版默认置顶，空白处穿透点击；`Ctrl+Shift+H`显示／隐藏，`Ctrl+Shift+0`恢复到主显示器。
- 托盘图标可显示窗口或退出。对手手牌和技能只发送数量；偷看结果只发给施法者。

## 规则

标准54张：每人17张，三张底牌归叫分最高的地主；三家不叫重新发牌。支持单张、对子、三张、三带、顺子、连对、飞机、四带二、炸弹与王炸。顺子不含2和王。四带二单允许带对子，飞机单翼可有重复点数，但翼不能用飞机主体点数。

连续两家不出：清空中央并抽技能，原领出者继续领出。地主每轮抽2、最多留3；农民各抽1、最多留2。库存超限时，全桌先等待超限者弃至上限，再继续出牌。

技能只能在自己的正常出牌回合使用，不消耗本次出牌机会，也没有独立技能阶段。可以连续使用持有的技能，或保留到以后。超限弃牌时不能通过使用技能腾位置。出牌超时自动不出，领出超时自动出最小单张；弃牌超时自动弃掉多余技能。正常打完最后一手立即获胜。

技能包括偷牌、送牌、偷看、赖子、送3、两换一、全桌洗手、双方各加三张、身份互换、塞两张、反转顺序。初始权重见玩法说明与 `src/shared/skills.ts`，不是经过胜率验证的最终平衡参数。

赖子单出算3，组合可代3～A、不代2和王、不参与炸弹。自己已有赖子时不能再生成，转移或洗手后可持有多张，每局最多生成三张。新增普通牌从3～2抽取，无新大小王；双方加三张只生成3～7。牌总数可超54张，五张同点数不是新炸弹。

反转立即改变后续出牌方向，当前使用者仍要正常出牌或选择不出；连续两次反转恢复原方向。如果当前使用者反转后选择不出，仍需让其他有权跟牌的人响应，不能跳回本轮最高牌主人并提前清桌。身份互换每局一次，不改变当前回合、桌面牌或已经抽到的技能，新身份立即决定库存上限，超限先弃后恢复原回合；下轮按新身份抽牌。全桌洗手每局两次。发生身份互换后关闭春天／反春天加倍；其他对局按标准触发。

## 开发与验证

需要 Node.js 24 与 pnpm 11：

```
pnpm install
pnpm test
pnpm build
pnpm start
pnpm desktop
pnpm run pack
```

`pnpm test`包含牌型、技能、正常回合使用、方向反转、库存上限、私牌隔离、真实三连接与陪练回归。浏览器操作验收运行 `pnpm test:browser`；打包客户端验收运行 `node scripts/desktop-playtest.mjs`。公网部署完成后可运行 `node scripts/remote-playtest.mjs`，它只操作自行创建的随机密码测试房并主动清理，不加入已有玩家房间。

开发网页可分别运行 `pnpm server:dev` 与 `pnpm dev`。生产服务只暴露打包后的 `dist` 静态文件及 `/ws`、`/health`，房间保存在单进程内存里；不要运行多实例共享同一地址。`/health`包含版本号与 `protocol: "turn-skills-v2"`，可用于确认Render已经更新到0.2.0规则。断线保留座位约三分钟，期间牌局暂停，服务重启则房间丢失。

牌型独立实现并参考 DouZero 开源规则结构，来源与许可证说明见 `THIRD_PARTY_NOTICES.md`。
